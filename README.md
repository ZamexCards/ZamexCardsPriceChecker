# ZamexCards Price Checker v8.2

Scanner-fixes:
- Een via de scanner gevonden kaart kan nu betrouwbaar worden toegevoegd aan `Jouw kaartenlijst`.
- De knop `+ Voeg toe aan lijst` gebruikt rechtstreeks de kaart die op dat moment in beeld staat.
- Na een succesvolle scan blijft de gevonden kaart als geselecteerde kaart actief.

Nieuwe foto-opties:
- `Scan nu` = live camera
- `Foto maken` = telefoon-camera / nieuw fotobestand
- `Uit galerij kiezen` = bestaand afbeeldingsbestand selecteren
- De galerij-input heeft bewust géén `capture` attribuut, zodat mobiele browsers de fotobibliotheek kunnen openen.

Alle functies uit v8.1 blijven behouden.

GitHub Pages:
Vervang alleen `index.html`, Commit changes, wacht kort en doe Ctrl+F5.
