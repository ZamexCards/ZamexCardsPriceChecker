# ZamexCards Price Checker v13 – AI Vision

Deze versie gebruikt server-side OpenAI Vision via Vercel.

## Belangrijk
De API key hoort alleen als Vercel Environment Variable `OPENAI_API_KEY` te bestaan.
Zet een API-key nooit in `index.html`.

## Bestanden
- `index.html` – complete Price Checker
- `scanner-test.html` – losse AI scanner test
- `api/scan.js` – beveiligde AI backend
- `api/health.js` – controle of backend/API-key is ingesteld
- `package.json` – OpenAI SDK
- `vercel.json` – Vercel functie-instelling
- `STAP-VOOR-STAP-NL.txt` – eenvoudige installatiehandleiding

Lees eerst `STAP-VOOR-STAP-NL.txt`.
